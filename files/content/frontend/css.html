CSS

CSS ou Folha de Estilo em Cascata, é uma linguagem para aplicar estilos no código HTML.

CSS é usado para cores, imagens de fundo, layouts e mais.

Anatomia basica de uma regra CSS:

Uma regra CSS é feita de duas partes. Um seletor e um bloco de declaraçao. Um seletor é um padrão usado no CSS para identificar e selecionar um elemento específico do HTML para estilização. Um bloco de declaraçao aplica um grupo de estilos para um seletor especifico ou grupo de seletores.

Basic syntax:


                selector {
                    property: value;
                }

meta name="viewport": Esse elemento dá ao navegador instruçoes para controlar as dimensões e escala da pagina em diferentes dispositivos, particularmente em dispositivos moveis e em tablets.

Estilo padrao do navegador: Cada elemento HTML vai ter um comportamento padrão a depender do navegador, como margens e espaçamentos padrão.

CSS Inline, Interno e Externo

CSS Inline é escrito diretamente no elemento HTML. ex:


                <link rel="stylesheet" href="styles.css">
                <p style="color: red;">Esse é um paragrafo vermelho.</p>

CSS Interno: Esses estilos são escritos dentro da tag <style> dentro da seção head do documento HTML. É o mais usado.

Trabalhando com propriedades width e height

Propriedade width: Largura de um documento. Se nao especificado, recebe auto.

min-width: Especifica a largura minima do documento.

max-width: Largura maxima do documento.

height: Altura do elemento. Se vazio, é definido auto.

min-height: Especifica a altura minima do documento.

max-height: Altura maxima do documento.

Diferentes Tipos de Combinadores CSS

Combinador descendente:

Esse combinador é usado para apontar elementos que são descendentes do elemento pai.

Temos o seguinte codigo HTML:


                <link rel="stylesheet" href="styles.css">
                <ul>
                    <li>Item 1 Exemplo</li>
                    <li>Item 2 Exemplo</li>
                    <li>Item 3 Exemplo</li>
                </ul>

O codigo CSS para chamar os itens dentro da lista nao ordenada:


                ul li {
                    background-color: yellow;
                }

Todos os elementos <li> terão cor amarelo.

Combinador filho:

Esse combinador é usado para selecionar elementos que são filhos diretos de um elemento pai especifico. O exemplo abaixo vai aplicar a todos os elementos <p> que sao filhos diretos da classe container.

Codigo HTML:


                <link rel="stylesheet" href="styles.css">
                <div class="container">
                    <p>Isso vai ser estilizado.</p>
                    <div>

                    <p>Isso nao vai ser estilizado.</p>
                    </div>
                </div>

Codigo CSS:


                .container > p {
                    background-color: black;
                    color: white;
                }
