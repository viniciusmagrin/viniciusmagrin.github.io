Linguagem JavaScript

Guia completo do JavaScript (Moderno / ES6+), abordando desde a sintaxe fundamental até os recursos avançados de assincronismo e manipulação de estruturas.

Fundamentos e Declarações

JavaScript é uma linguagem de tipagem dinâmica e fraca, executada por motores como V8 (Node.js/Chrome).

  • Variáveis:

    • const: Para identificadores que não serão reatribuídos (escopo de bloco).
    • let: Para variáveis que serão reatribuídas (escopo de bloco).
    • var: : Modo legado (escopo de função / sofre hoisting). Evite.

  • Tipos de dados:

    string, number (inteiros e decimais usam o mesmo tipo), boolean, null, undefined

    symbol Simbolos sao unicos e imutaveis, usados, como identificadores para propriedades de objetos

    bigint Para declarar um bigint, no proprio numero declarado se adiciona n, exemplo: const bigNumber = 123n

    object Um objeto contem diversos dados do tipo chave-valor. A chave é o nome da propriedade e o valor é o valor da propriedade.

    Uma variavel pode ser indefinida undefined ou nula null.

  • Aspas

    Both 'single' and "double" quotes are allowed to be used in strings.

  • Concatenação (Junção de texto)

    • 
                        let nomeEstudante = "Asad";
                        let idadeEstudante = 25;
                        console.log(nomeEstudante + " is " + idadeEstudante + " years.");
    Para adicionar texto a texto ja existente: 
    
                        let mensagem = "Bem vindo à programacao, ";
                        mensagem += "Joao!";
                        console.log(mensagem); // Resultado: Bem vindo à programacao, Joao!
    Usando a funçao concat(): 
    
                        let primeiroNome = "Joao";
                        let ultimoNome = "Azevedo";
                        let nomeCompleto = primeiroNome.concat(" ", ultimoNome);
                        console.log(nomeCompleto); // Saida: Joao Azevedo

  • Interpolação de Strings (Template Literals):

    Uso de crases ` ` com ${expressão}. 

    const nome = "Vinicius";
    let idade = 25;
    const ativo = true;

    // Template Literal
    console.log(`Usuário: ${nome}, Idade: ${idade}`);

Operadores e Comparações

  • Atribuição:

    =

  • Aritméticos

    +, -, *, /, % (resto), ** (exponenciação)/.

  • Incremento/Decremento:

    ++, --

  • Comparação Estrita vs Fraca:

    • === e !==: Comparação estrita (compara valor e tipo). Padrão recomendado.
    • == e !=: Comparação fraca (realiza conversão implícita de tipo antes de comparar).

  • Operador Ternário

    condicao ? valorSeVerdadeiro : valorSeFalso

  • Operador de Coalescência Nula (??):

    Retorna o lado direito se o esquerdo for null ou undefined.

  • Encadeamento Opcional (?.):

    Acessa propriedades de um objeto sem causar erro caso um nível intermediário seja null ou undefined. 

    const x = 5;
    const y = "5";

    console.log(x == y);  // true (conversão implícita)
    console.log(x === y); // false (tipos diferentes: number vs string)

    // Coalescência Nula e Encadeamento Opcional
    const usuario = { perfil: { cidade: "Cordeirópolis" } };
    const cidade = usuario?.perfil?.cidade ?? "Desconhecida";

Estruturas de Controle e Laços

    • Condicionais:

      if, else if, else e switch

    • Laços de Repetição:

      • for: Iteração tradicional indexada.
      • while / do...while: Iteração baseada em condição.
      • for...of: Itera sobre valores de iteráveis (arrays, strings).
      • for...in: Itera sobre as chaves/propriedades de um objeto.
    • 
    // for...of em Arrays
    const numeros = [10, 20, 30];
    for (const num of numeros) {
        console.log(num);
    }

    // for...in em Objetos
    const carro = { marca: "Ford", modelo: "Focus" };
    for (const chave in carro) {
        console.log(`${chave}: ${carro[chave]}`);
    }

    Funções

    JavaScript trata funções como cidadãs de primeira classe (first-class citizens), permitindo que sejam passadas como argumentos, atribuídas a variáveis e retornadas por outras funções.

    • Declaraçao Tradicional:

      Possui hoisting (pode ser chamada antes de sua definição).

    • Expressão de Função & Arrow Functions:

      Não possuem hoisting. Arrow functions possuem sintaxe concisa e não vinculam o próprio this. 
    
    // Tradicional
    function somar(a, b = 0) { // Valor padrão no parâmetro
        return a + b;
    }

    // Arrow Function
    const multiplicar = (a, b) => a * b;

    // Arrow Function com corpo estendido
    const calcularMedia = (n1, n2) => {
        const soma = n1 + n2;
        return soma / 2;
    };

    Arrays e Métodos Funcionais

    Em JS, arrays sao objetos dinâmicos e heterogêneos

    • .push(), .pop(), .shift(), .unshift(): Adição e remoção nas extremidades.

    • Métodos Iterativos (HOFs - Higher Order Functions):

      • .forEach(): Executa uma função para cada elemento.
      • .map(): Transforma os elementos e retorna um novo array.
      • .filter(): Retorna um novo array contendo apenas os elementos que passam no teste.
      • .reduce(): Acumula os valores do array em um único valor final.
      • .find() / .findIndex(): Localiza elemento/índice com base em condição.
                  
    const nums = [1, 2, 3, 4, 5];

    // Dobra apenas os números pares
    const paresDobrados = nums
        .filter(n => n % 2 === 0)
        .map(n => n * 2); // [4, 8]

    // Soma de todos os elementos
    const somaTotal = nums.reduce((acumulador, atual) => acumulador + atual, 0); // 15

    Desestruturação e Operador Rest/Spread

    • Spread (...):

    • Rest (...)

                    
// Desestruturação de Objeto
const usuario = { id: 1, nome: "Ana", cargo: "Dev" };

function somarTudo(...valores) {

}

    Orientação a Objetos (Classes e Protótipos)

    O JavaScript utiliza herança baseada em Protótipos. O ES6 introduziu a sintaxe de class como uma camada sintática (syntactic sugar) sobre o sistema prototípico.

                    
class Dispositivo {
    #ligado = false; // Campo privado (ES2022)

    constructor(nome) {
        this.nome = nome;
    }

    ligar() {
        this.#ligado = true;
        console.log(`${this.nome} ligado.`);
    }

    get estaLigado() {
        return this.#ligado;
    }
}

// Herança
class Smartphone extends Dispositivo {
    constructor(nome, sistema) {
        super(nome);
        this.sistema = sistema;
    }
}

const meuCelular = new Smartphone("Galaxy", "Android");
meuCelular.ligar();

    Programação Assíncrona

    Como o runtime do JavaScript roda em uma thread única (Single-Threaded Event Loop), operações de E/S (leitura de arquivos, chamadas de rede) usam modelos assíncronos não-bloqueantes.

    Promises

    Objeto representando a eventual conclusão ou falha de uma operação assíncrona.

                    
const buscarDados = () => {
return new Promise((resolve, reject) => {
    const sucesso = true;
    setTimeout(() => {
        if (sucesso) resolve("Dados carregados");
        else reject("Erro ao carregar");
    }, 1000);
});
};

buscarDados()
.then(resposta => console.log(resposta))
.catch(erro => console.error(erro));

    Async / Await

    Sintaxe moderna que permite escrever código assíncrono com aparência síncrona.

                    
async function executarProcesso() {
    try {
        const resultado = await buscarDados();
        console.log(resultado);
    } catch (erro) {
        console.error("Tratamento de erro:", erro);
    }
}

executarProcesso();

    Módulos (ES Modules)

    Utilizados para organizar o código em múltiplos arquivos usando export e import.

                    
// arquivo: mathUtils.js
export const PI = 3.14159;
export function somar(a, b) {
    return a + b;
}
export default function subtrair(a, b) {
    return a - b;
}

// arquivo: main.js
import subtrair, { PI, somar } from './mathUtils.js';
