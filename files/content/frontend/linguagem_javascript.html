Trabalhando com texto

Ao trabalhar com texto, vale lembrar que strings sao imutaveis, portanto os metodos vao ter que ser retornados em uma nova variavel.

slice(inicio, fim) Define o inicio (do zero) e fim de onde sera recortado. Retorna o texto em uma nova variável, visto que strings sao imutáveis. Permite negativos, para pegar os ultimos caracteres por exemplo.

repeat(n) Repete a string n vezes. Se colocar zero, devolve uma string vazia "". Se passar numero decimal, converte para inteiro, truncanco a parte decimal.

indexOf(trecho, posInicial) busca um trecho de texto para saber se ele existe. Se o trecho nao existir. retorna -1. Pode ser usado para saber se um texto existe e depois cortar com slice() por exemplo.

replace(alvo, substituto) Encontra um 'alvo' e troca por um 'substituto'

replaceAll(alvo, substituto) Troca todas as ocorrencias do 'alvo pelo 'substituto'.'

includes(trecho) Só avalia se existe ou nao o 'trecho', sem informar a posiçao exata.

trim(), trimStart(), trimEnd() Remove espaços em branco, tabs e quebras de linha das extremidades. É fundamental antes de comparar ou converter entradas de texto.

split(separador) Quebra a string em um array de pedaços, usando o 'separador', que normalmente é ",", "-", "-" ou " ", facilitando processar cada parte separadamente.

padStart(tamTotal, preenchimento) / padEnd(...) Completa o texto ate atingir um comprimento minimo. Muito usado para zeros a esquerda, como formatar dias, meses ou codigos.

Zero a esquerda com padStart


                        const diaSimples = "5";
                        const diaFormatado = diaSimples.padStart(2, "0"); // 05

                        const diaDuplo = 15;
                        const diaMantido = diaDuplo.padStart(2, "0"); // 15

Alinhamento a direita com padEnd

Digamos que queira um codigo com 8 caracteres preenchidos com traços "-": 


                            const codigo = "ID-42";
                            const codigoAlinhado = codigo.padEnd(8, "-"); // "ID-42---"

Preenchimento com mais de um caractere

Se o texto tiver tamanho 2 e voce pedir um tamanho 7, preenchendo com "xy" ele repete "xy" e corta no limite exato para nao passar de 7 caracteres (okxyxyx) const base = "ok"; const preenchido = base.padEnd(7, "xy"); // "okxyxyx"

Obs: padStart e padEnd sao metodos de string, entao em um numero como 5, primeiro converter pra texto: String(5).padStart(2, "0")

Operadores e Comparações

  • Atribuição:

    =

  • Aritméticos

    +, -, *, /, % (resto), ** (exponenciação)/.

    Obs: Quando se usa o operador + com um numero e uma string, JS converte o numero em uma string e concatena os dois valores.

    Se forem os operadores - * / JS converte a string em numero e o resultado sera um numero.

    Para null e undefined, JS trata null como 0 e undefined como NaN em operaçoes matematicas.

  • Incremento/Decremento:

    ++, --

    ++num aumenta o valor da variavel e depois retorna o novo valor.

    num++ retorna o valor atual e aumenta o valor da variavel.

    Atribuiçao composta

    +=, -=, *=, /= Faz a operaçao e atribui o resulto para a variavel

    %= Divide a variavel pelo numero especificado e atribui o resto para a variavel

    **= Eleva a variavel à potencia do numero especificado e reatribui o resultado à variavel.

  • Comparação Estrita vs Fraca:

    • === e !==: Comparação estrita (compara valor e tipo). Padrão recomendado.
    • == e !=: Comparação fraca (realiza conversão implícita de tipo antes de comparar).

  • Operadores de Comparaçao

    > Maior que (Checa se o valor da esquerda é maior que o da direita)

    >= Maior ou igual que

    < Menor que

    <= Menor ou igual que

    Operadores Unários

    Convertem os operandos em numeros

    + "42" // converte para 42

    - "42" // converte para -42

    ! Inverte o valor booleano. Se true, vira false ou vice versa.

    Operadores bit a bit

    & Operador AND: O operador E retorna 1 se ambos os operandos sao 1

    &= Operador AND Composto: O operador E Composto realiza um AND bit a bit com o numero especificado e aplica o valor resultante à variavel.

    | Operador OR:O operador OU retorna 1 se um dos bits do operando for 1. Ex: [0,1] ou [1,0]

    |= Operador OU Composto: efetua um OU bit a bit com o numero especificado e aplica o valor resultante à variavel.

    XOR Operador OU Exclusivo: Retorna 1 quando um dos operadores for 1, mas retorna zero se ambos forem 1 ou ambos forem zero.

    ~ Operador NOT: Inverte a representaçao binaria de um numero.

    << Left Shift Operator, ou Operador de Deslocamento à Esquerda muda todos os bits para a esquerda em uma quantidade especificada de posiçoes.

    >> Right Shift Operator, ou Operador de Deslocamento à Direita muda todos os bits para a direita em uma quantidade especificad de posiçoes.

  • Operador de Coalescência Nula (??):

    Retorna o lado direito se o esquerdo for null ou undefined.

  • Encadeamento Opcional (?.):

    Acessa propriedades de um objeto sem causar erro caso um nível intermediário seja null ou undefined. 

    const x = 5;
    const y = "5";

    console.log(x == y);  // true (conversão implícita)
    console.log(x === y); // false (tipos diferentes: number vs string)

    // Coalescência Nula e Encadeamento Opcional
    const usuario = { perfil: { cidade: "Cordeirópolis" } };
    const cidade = usuario?.perfil?.cidade ?? "Desconhecida";

    Operadores Binarios Logicos

    && O operador AND checa se ambos os operadores sao verdadeiros. Se sim, retorna um valor. Se um dos operadores for falso, retorna o primeiro valor falso.

    || O operador OU checa se pelo menos uma das operaçoes é verdadeira.

    ?? Operador de Coalescência Nula: Retorna um valor se o primeiro é null ou undefined.

    Ex: console.log(quantEstoque ?? 10) Se a quantidade em estoque for null ou undefined, ele usa o 10 como valor.

    Funções

    JavaScript trata funções como cidadãs de primeira classe (first-class citizens), permitindo que sejam passadas como argumentos, atribuídas a variáveis e retornadas por outras funções.

    • Declaraçao Tradicional:

      Possui hoisting (pode ser chamada antes de sua definição).

    • Expressão de Função & Arrow Functions:

      Não possuem hoisting. Arrow functions possuem sintaxe concisa e não vinculam o próprio this. 
    
    // Tradicional
    function somar(a, b = 0) { // Valor padrão no parâmetro
        return a + b;
    }

    // Arrow Function
    const multiplicar = (a, b) => a * b;

    // Arrow Function com corpo estendido
    const calcularMedia = (n1, n2) => {
        const soma = n1 + n2;
        return soma / 2;
    };

    Arrays e Métodos Funcionais

    Em JS, arrays sao objetos dinâmicos e heterogêneos

    • .push(), .pop(), .shift(), .unshift(): Adição e remoção nas extremidades.

    • Métodos Iterativos (HOFs - Higher Order Functions):

      • .forEach(): Executa uma função para cada elemento.
      • .map(): Transforma os elementos e retorna um novo array.
      • .filter(): Retorna um novo array contendo apenas os elementos que passam no teste.
      • .reduce(): Acumula os valores do array em um único valor final.
      • .find() / .findIndex(): Localiza elemento/índice com base em condição.
                  
    const nums = [1, 2, 3, 4, 5];

    // Dobra apenas os números pares
    const paresDobrados = nums
        .filter(n => n % 2 === 0)
        .map(n => n * 2); // [4, 8]

    // Soma de todos os elementos
    const somaTotal = nums.reduce((acumulador, atual) => acumulador + atual, 0); // 15

    Orientação a Objetos (Classes e Protótipos)

    O JavaScript utiliza herança baseada em Protótipos. O ES6 introduziu a sintaxe de class como uma camada sintática (syntactic sugar) sobre o sistema prototípico.

                    
class Dispositivo {
    #ligado = false; // Campo privado (ES2022)

    constructor(nome) {
        this.nome = nome;
    }

    ligar() {
        this.#ligado = true;
        console.log(`${this.nome} ligado.`);
    }

    get estaLigado() {
        return this.#ligado;
    }
}

// Herança
class Smartphone extends Dispositivo {
    constructor(nome, sistema) {
        super(nome);
        this.sistema = sistema;
    }
}

const meuCelular = new Smartphone("Galaxy", "Android");
meuCelular.ligar();

    Programação Assíncrona

    Como o runtime do JavaScript roda em uma thread única (Single-Threaded Event Loop), operações de E/S (leitura de arquivos, chamadas de rede) usam modelos assíncronos não-bloqueantes.

    Promises

    Objeto representando a eventual conclusão ou falha de uma operação assíncrona.

                    
const buscarDados = () => {
return new Promise((resolve, reject) => {
    const sucesso = true;
    setTimeout(() => {
        if (sucesso) resolve("Dados carregados");
        else reject("Erro ao carregar");
    }, 1000);
});
};

buscarDados()
.then(resposta => console.log(resposta))
.catch(erro => console.error(erro));

    Async / Await

    Sintaxe moderna que permite escrever código assíncrono com aparência síncrona.

                    
async function executarProcesso() {
    try {
        const resultado = await buscarDados();
        console.log(resultado);
    } catch (erro) {
        console.error("Tratamento de erro:", erro);
    }
}

executarProcesso();

    Metodos Comuns para Numeros

    isNaN() NaN significa "Not-a-Number", ou seja, não-número. Representa um valor numerico indefinido ou impossivel de ser representado. A função isNaN() serve para checar se um valor é um numero ou nao.

    Number.isNaN() é mais confiável par checar numeros, especialmente onde coerçao de tipo pode gerar resultados inesperados.

    parseFloat() Esse metodo analisa uma string e retorna um numero de ponto flutuante (float). É usada para extrair numeros do inicio de uma string, mesmo que esta contenha valores nao numericos depois do numero.

    parseInt O método analisa uma string e retorna um inteiro. Ele para de analisar assim que encontra o primeiro caractere que nao seja numero. Para números de ponto flutuante, retorna somente a parte inteira. Se nao encontra um numero valido, retorna NaN

    toFixed Esse método é chamado em um numero e pega um argumento opcional, que é o numero de digitos que aparece depois do ponto decimal. Retorna uma representaçao do numero atraves de uma string com o numero especificado de casas decimais.
    Ex: 

    
                const valorOriginal = 4.56765446;
                const textoFormatado = valorOriginal.toFixed(2); // resulta em "4.57" (uma string)
                const numFormatado = parseFloat(textoFormatado); // resulta em 4.57 (um number de ponto flutuante)
                const intFormatado = parseInt(textoFormatado); // retorna o valor até o primeiro caractere nao numerico
