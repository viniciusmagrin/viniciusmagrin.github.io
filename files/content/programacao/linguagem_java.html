Linguagem Java

Estrutura basica em um exemplo:

Abaixo temos a estrutura basica de codigo java:


package classes_e_objetos;

import java.util.Scanner;

public class Exemplo1_Classes_e_Objetos {
    public static void main(String[] args) {

        Scanner teclado = new Scanner(System.in);

        System.out.print("Digite o nome do carro: ");
        String nome = teclado.nextLine();

        System.out.print("Digite o modelo do carro: ");
        String modelo = teclado.nextLine();

        System.out.print("Digite o ano do carro: ");
        int ano = teclado.nextInt();

        Carro meuCarro = new Carro(nome, modelo, ano);

        meuCarro.exibirInformacoes();

        teclado.close();

    }

}

class Carro {
    String nome;
    String modelo;
    int ano;

    Carro(String nome, String modelo, int ano){
        this.nome = nome;
        this.modelo = modelo;
        this.ano = ano;
    }

    void exibirInformacoes(){
        System.out.println("\n====== INFORMACOES DO CARRO =====");
        System.out.println("Nome: " + nome);
        System.out.println("Modelo: " + modelo);
        System.out.println("Ano: " + ano);
        System.out.println("====================================");
    }
}

Explicação:

package classes_e_objetos; => Define o pacote onde a classe esta localizada. Pacotes em Java funcionam como "pastas virtuais", para organizar as classes.

import java.util.Scanner; => Importa a classe Scanner do pacote java.util. O Scanner é uma classe utilitaria que permite ler dados de entrada, como texto, numero, etc digitado pelo usuario no teclado ou vindo de arquivos ou fluxos de dados

public class Exemplo1_Classes_e_Objetos { => Inicio da definicao da classe publica "Exemplo1_Classes_e_Objetos". public indica que essa classe pode ser acessada de qualquer lugar do projeto.

public static void main(String[] args) { => Em Java, o metodo main é o ponto de entrada da aplicaçao, sendo executado quando o programa inicia. É obrigatório para a execução.

  • public: pode ser acessado de qualquer lugar.
  • static: pode ser executado sem precisar criar um objeto de classe.
  • void: nao retorna nenhum valor.
  • String[] args: permite passar parametros pela linha de comando.

Scanner teclado = new Scanner(System.in); Criaçao de um objeto Scanner chamado "teclado". Esse objeto sera responsavel por capturar os dados digitados pelo usuario no console. System.in representa a entrada padrao (normalmente o teclado).

String modelo = teclado.nextLine(); Captura o nome digitado pelo usuario. nextLine() lê uma linha completa de texto ate o usuario pressionar 'Enter'. O valor digitado sera armazenado na variavel "nome".

Carro meuCarro = new Carro(nome, modelo, ano); Instanciaçao de um objeto da classe "Carro". A palavra chave "new" é usada para criar um novo objeto em memoria. O construtor da classe Carro sera chamado, recebendo como parametros os valores digitados. O objeto criado sera armazenado na variavel de referencia "meuCarro".

meuCarro.exibirInformacoes(); Chamada do metodo "exibirInformacoes" do objeto "meuCarro". Isso fará com que o carro mostre na tela todos os dados formatados.

teclado.close(); Fechamento do objeto Scanner. É uma boa pratica fechar o Scanner quando nao for mais utilizado, para liberar recursos do sistema operacional e evitar vazamentos de memoria.

class Carro { Definiçao da classe carro. Uma classe é como um molde ou modelo que descreve as caracteristicas (atributos) e os comportamentos (metodos) que os objetos deste tipo terao.


    String nome;
    String modelo;
    int ano;
Atributos da classe carro. Tambem são chamados de "variaveis de instancia". Representam as caracteristicas (propriedades) do objeto.

Carro(String nome, String modelo, int ano) { Construtor da classe Carro. O construtor é um metodo especial chamado automaticamente quando usamos "new". Ele tem o mesmo nome da classe e nao possui nenhum tipo de retorno. Sua funçao é inicializar os atributos do objeto com os valores passados como parametros.

this.nome = nome; "this" referencia o proprio objeto. Diferencia os atributos do objeto (this.nome) dos parametros recebidos (nome). Assim evitamos ambiguidade.

void exibirInformacoes() {conteudo} Metodo para imprimir no console os dados do carro. Metodos sao comportamentos (funcoes) que os objetos podem executar.
