Linguagem C

Linguagem compilada de baixo nivel / procedural. Ver Mais

C é uma linguagem classica e de altissima performance, que serve como base para a computaçao moderna. É amplamente utilizada no desenvolvimento de sistemas operacionais, compiladores, drivers e sistemas embarcados devido ao seu controle sobre a memoria.

Linguagem Pascal

Linguagem compilada de alto nivel / estruturada. Ver Mais

Pascal é uma linguagem clássica, estruturada e de forte tipagem, desenvolvida originalmente para ensinar boas práticas de programação. É amplamente conhecida pela sua sintaxe clara e legível, sendo utilizada no desenvolvimento de softwares acadêmicos, sistemas comerciais e aplicações desktop (especialmente com o Delphi, Lazarus ou Object Pascal) devido ao seu alto nível de organização e segurança de código.
