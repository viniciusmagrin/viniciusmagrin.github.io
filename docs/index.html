Linguagem C

Linguagem compilada de baixo nível / procedural

C é uma linguagem clássica e de altíssima performance, que serve como base para a computação moderna. É amplamente utilizada no desenvolvimento de sistemas operacionais, compiladores, drivers e sistemas embarcados devido ao seu controle sobre a memoria.

BASH

Shell Script / Linha de comando (Unix/Linux)

Linguagem de script e interpretador de comandos nativo de sistemas Linux e macOS. É a ferramenta fundamental para automaçao de tarefas no terminal, administração de servidores, navegação no sistema e manipulação de arquivos.

HTML

Linguagem de marcação (HyperText Markup Language)

A espinha dorsal da web. Não é uma linguagem de programação, mas sim de marcação, responsável por definir a estrutura e a organização do conteúdo de uma página web (textos, imagens, links, tabelas, formulários).

PHP

Linguagem de Script Server-Side

Linguagem voltada para o desenvolvimento web backend. Executa no servidor para processar regras de negócio, conectar ao banco de dados e gerar páginas HTML de forma dinâmica antes de enviá-la ao navegador.

SQL

Linguagem de consulta Estruturada (Structured Query Language)

O padrão universal para interação com bancos de dados relacionais. É utilizado para criar, consultar, atualizar e gerenciar dados armazenados em tabelas, garantindo a integridade e o relacionamento das informações.
